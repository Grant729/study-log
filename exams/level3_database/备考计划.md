## 四、环境结论（重大更正）

- **考试平台是 MySQL**——你本机的 **MySQL 8.0.23 就是备考平台**，Navicat + VS Code `%%sql` 继续用，**无需 SQL Server**

- 本机 MySQL 已实测支持考试全范围：中文库表列名、DDL/DML/JOIN/子查询/存储过程/触发器/授权全部可用；练习库 `exam_practice` 已建好

## 六、每日节奏（约 3 小时）· 三部分 + 每日回炉

> 2026-10-03 起按用户反馈改造（用户实际基础≈零：半年前学的已全忘）。每天结构：
> **① 知识讲义**（理论用比喻讲生动 + 实操范例**逐词解析**）→ **② 理论题检测** → **③ 代码实操** → **④ 回炉**。
> 铁律：**②③ 与①"换汤不换药"**——知识框架相同、具体内核必须换（范例教"借阅量求最大值"，考题就换成"逾期数求最大值"）。
> 所有题目**书面作答发教练批改**，批改后才看折叠答案。

| 时长 | 内容 |
|---|---|
| 60~90 min | 第①部分：读当日知识讲义，跟着范例在自己的 MySQL 里跑一遍（先看懂再做题） |
| 45~60 min | 第②部分：理论题检测（书面作答 → 发教练批改 → 看折叠答案 → 错题入册） |
| 45~60 min | 第③部分：代码实操（换汤不换药的新场景，手打 SQL，报错先自己想） |
| 15~20 min | 第④部分：**回炉**（3~5 道小题，全部来自前几天学过的旧知识点，同样书面作答；机制见下） |
| 10 min | 错题归档 + VS Code 提交 commit |

### 记忆机制（2026-10-03 用户确立的原则）

不靠死记硬背，靠**理解基础上的反复接触**：每个知识点、每类 SQL 在学完后的 **次日、第 4 天、第 8~10 天、复习日/真题/冲刺** 各回炉一次（1 → 4 → 8 阶梯），目标是"**知道 → 明白 → 懂 → 会用**"逐级加深。

- 回炉题由教练按 [回炉日历.md](回炉日历.md) 自动排入每天的第④部分：**旧知识占当天题量约 20~30%**（理论背诵点 + SQL 变体），SQL 回炉同样"换汤不换药"
- 回炉题**优先取用户错过的题**（错题本驱动）——错过的知识点会更快、更多次地再出现，直到做对两次以上
- 排期由教练全权维护，用户零管理成本，只需做题
- 知识点五级进阶（对应每日四部分）：**①讲义=知道、明白 → ②理论题=懂 → ③实操=会用 → ④回炉=不忘**
