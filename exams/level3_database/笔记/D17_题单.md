# ② 理论题检测（模块 7 · 用户与权限）

## 题 1【判断】新用户的默认权限

刚用 `CREATE USER` 建好的新用户，默认拥有数据库的所有权限。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**错。** 新用户默认只有 `USAGE`——**没有任何实际权限**，只表示"能连接"（讲义单元三）。要给权限必须 `GRANT`。

</details>

---

## 题 2【单选】创建用户

在 MySQL 中创建用户 `tom`（只允许本机登录，密码 `abc123`），正确语句是（ ）。

A. `CREATE USER 'tom'@'localhost' IDENTIFIED BY 'abc123'`
B. `CREATE USER tom IDENTIFIED 'abc123'`
C. `CREATE LOGIN tom PASSWORD 'abc123'`
D. `CREATE USER 'tom' IDENTIFIED WITH 'abc123'`

<details><summary>👉 点开对照答案与解析</summary>

**A。** 用户 = `用户名@主机`，密码用 `IDENTIFIED BY`（讲义单元二）。C 是 SQL Server 的写法。

</details>

---

## 题 3【单选】GRANT 的语法结构

`GRANT` 语句的三段式是（ ）。

A. `GRANT 用户 ON 权限 TO 对象`
B. `GRANT 权限 ON 对象 TO 用户`
C. `GRANT 对象 TO 权限 ON 用户`
D. `GRANT TO 用户 权限 对象`

<details><summary>👉 点开对照答案与解析</summary>

**B。** 三段式：**给谁（TO）· 对什么（ON）· 什么权限（GRANT）**。记成倒装：`GRANT 权限 ON 对象 TO 用户`。

</details>

---

## 题 4【单选】权限对象的层级

`GRANT SELECT ON exam_practice.读者 TO ...` 中，权限的作用范围是（ ）。

A. 所有数据库的所有表
B. exam_practice 库的所有表
C. **exam_practice 库的"读者"这一张表**
D. 只有"读者"这一列

<details><summary>👉 点开对照答案与解析</summary>

**C（表级）。** 三个层级：`*.*`（全局）→ `库.*`（库级）→ `库.表`（表级）。这里是表级。

</details>

---

## 题 5【判断】WITH GRANT OPTION

`GRANT ... WITH GRANT OPTION` 表示被授权的用户可以把这份权限再转授给别人。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** `WITH GRANT OPTION` = 允许转授权（讲义单元三）。生产环境要慎用，权限链可能失控。

</details>

---

## 题 6【单选】回收权限

回收用户对某张表的 SELECT 权限，正确语句是（ ）。

A. `DELETE SELECT ON exam_practice.读者 FROM 'u'@'localhost'`
B. `REVOKE SELECT ON exam_practice.读者 FROM 'u'@'localhost'`
C. `DROP SELECT ON exam_practice.读者 FROM 'u'@'localhost'`
D. `REMOVE SELECT ON exam_practice.读者 FROM 'u'@'localhost'`

<details><summary>👉 点开对照答案与解析</summary>

**B。** REVOKE 和 GRANT 对称：`REVOKE 权限 ON 对象 FROM 用户`。

</details>

---

## 题 7【判断】回收全部权限的语法

回收一个用户的全部权限，可以写 `REVOKE ALL PRIVILEGES ON *.* FROM 'u'@'localhost'`。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**错。** 回收全部权限的标准写法是 **`REVOKE ALL PRIVILEGES, GRANT OPTION FROM 'u'@'localhost'`**——**没有 `ON 对象`**（讲义单元四）。这是最容易写错的一句。

</details>

---

## 题 8【单选】查看权限

查看某个用户拥有哪些权限，使用（ ）。

A. `SHOW GRANTS FOR 'u'@'localhost'`
B. `SELECT GRANTS`
C. `SHOW PRIVILEGES FOR 'u'@'localhost'`
D. `DESCRIBE USER 'u'@'localhost'`

<details><summary>👉 点开对照答案与解析</summary>

**A。** `SHOW GRANTS FOR 用户`，会逐行列出已授予的权限。第一行通常是 `GRANT USAGE ON *.*`。

</details>

---

## 题 9【单选】权限不足的错误码

用户没有某张表的 INSERT 权限却执行了 INSERT，MySQL 报的错误码是（ ）。

A. 1062　B. 1142　C. 1452　D. 3819

<details><summary>👉 点开对照答案与解析</summary>

**B（1142）。** 1142 = 权限不足（command denied）。前面学过的：1062 重复、1048 空值、1452 外键、3819 CHECK。

</details>

---

## 题 10【判断】角色

角色（Role）可以理解成"一组权限的集合"，把角色授予用户后，用户就获得了角色里的所有权限。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 角色 = 权限打包（MySQL 8.0 支持）。`CREATE ROLE` → `GRANT 权限 TO 角色` → `GRANT 角色 TO 用户`。

</details>

# ③ SQL 实操（用户与权限）

> **每题一个 `%%sql` 格**。做完按题 5 删掉测试用户。
> 注：本笔记本是以 `root` 连的，`SHOW GRANTS` 用来验证授权结果即可（考试就考语法）。

## 实操题 1：创建用户并查看初始权限

**要求**：创建用户 `'d17_stu'@'localhost'`，密码 `'Stu@12345'`，然后 `SHOW GRANTS FOR` 查看它的权限。

**预期输出**：
```
GRANT USAGE ON *.* TO `d17_stu`@`localhost`
```

<details><summary>👉 点开折叠答案</summary>

```sql
DROP USER IF EXISTS 'd17_stu'@'localhost';
CREATE USER 'd17_stu'@'localhost' IDENTIFIED BY 'Stu@12345';
SHOW GRANTS FOR 'd17_stu'@'localhost';
```

**要点**：新用户只有 `USAGE`（无实际权限）。

</details>

---

## 实操题 2：授予"查图书表"的权限

**要求**：给 `d17_stu` 授予 `exam_practice.图书` 的 `SELECT` 权限，再 `SHOW GRANTS` 查看。

**预期输出**（两行）：
```
GRANT USAGE ON *.* TO `d17_stu`@`localhost`
GRANT SELECT ON `exam_practice`.`图书` TO `d17_stu`@`localhost`
```

<details><summary>👉 点开折叠答案</summary>

```sql
GRANT SELECT ON exam_practice.图书 TO 'd17_stu'@'localhost';
SHOW GRANTS FOR 'd17_stu'@'localhost';
```

**要点**：`GRANT 权限 ON 库.表 TO 用户`——表级授权。

</details>

---

## 实操题 3：授予"查 + 插借阅表"的权限

**要求**：给 `d17_stu` 授予 `exam_practice.借阅` 的 `SELECT` 和 `INSERT` 权限，再 `SHOW GRANTS` 查看。

**预期输出**（三行，注意借阅那行是两个权限写在一起）：
```
GRANT USAGE ON *.* TO `d17_stu`@`localhost`
GRANT SELECT, INSERT ON `exam_practice`.`借阅` TO `d17_stu`@`localhost`
GRANT SELECT ON `exam_practice`.`图书` TO `d17_stu`@`localhost`
```

<details><summary>👉 点开折叠答案</summary>

```sql
GRANT SELECT, INSERT ON exam_practice.借阅 TO 'd17_stu'@'localhost';
SHOW GRANTS FOR 'd17_stu'@'localhost';
```

**要点**：多个权限用逗号隔开，MySQL 会把同一张表的权限合并显示在一行。

</details>

---

## 实操题 4：回收 INSERT 权限

**要求**：把 `d17_stu` 对 `exam_practice.借阅` 的 **INSERT** 权限收回来，再 `SHOW GRANTS` 确认只剩 SELECT。

**预期输出**：
```
GRANT USAGE ON *.* TO `d17_stu`@`localhost`
GRANT SELECT ON `exam_practice`.`借阅` TO `d17_stu`@`localhost`
GRANT SELECT ON `exam_practice`.`图书` TO `d17_stu`@`localhost`
```

<details><summary>👉 点开折叠答案</summary>

```sql
REVOKE INSERT ON exam_practice.借阅 FROM 'd17_stu'@'localhost';
SHOW GRANTS FOR 'd17_stu'@'localhost';
```

**要点**：`REVOKE 权限 ON 对象 FROM 用户`——和 GRANT 对称，只是 `TO` 换成 `FROM`。

</details>

---

## 实操题 5：删除用户并确认

**要求**：删除用户 `'d17_stu'@'localhost'`，然后查 `mysql.user` 确认它已不存在。

**预期输出**：
```
0
```

<details><summary>👉 点开折叠答案</summary>

```sql
DROP USER 'd17_stu'@'localhost';
SELECT COUNT(*) FROM mysql.user WHERE user = 'd17_stu';
```

**要点**：`DROP USER '用户名'@'主机'`；确认用的 `mysql.user` 是系统表，记录所有用户。

</details>

## 回 1【判断】触发器怎么执行

触发器不需要手动调用，表上发生 INSERT/UPDATE/DELETE 时会自动执行。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 触发器 = 绑定在表上的"自动反应"；存储过程才需要 `CALL`。

</details>

## 回 2【单选】DELETE 触发器用谁

在 `DELETE` 触发器里，引用被删除那一行旧值的是（ ）。

A. `NEW.列`　B. `OLD.列`　C. 两者都行　D. 都不行

<details><summary>👉 点开对照答案与解析</summary>

**B（OLD）。** INSERT 只有 NEW、DELETE 只有 OLD、UPDATE 两个都有。你 D16 题 2 就是用 `OLD.读者编号` 写的。

## 回 3【单选】ACID 的隔离性

事务的 ACID 中，"并发事务之间互不干扰"指的是（ ）。

A. 原子性　B. 一致性　C. 隔离性　D. 持久性

<details><summary>👉 点开对照答案与解析</summary>

**C。** 原子=全或全不、一致=不乱、隔离=不扰、持久=不丢。

</details>

## 回 4【单选】三级封锁协议

三级封锁协议能防止（ ）。

A. 只防丢失修改　B. 只防读脏数据　C. **丢失修改 + 读脏 + 不可重复读**　D. 只防死锁

<details><summary>👉 点开对照答案与解析</summary>

**C。** 一级防丢失修改 → 二级再防读脏 → 三级再防不可重复读。

</details>

## 回 5【单选】M:N 的转换

M:N 联系转换成关系模式时，应该（ ）。

A. 不单独建表，一端键放另一端
B. **单独建表，主键 = 两端实体键的组合**
C. 删掉联系
D. 只建联系属性的表

<details><summary>👉 点开对照答案与解析</summary>

**B。** M:N 必须单独建表，主键 = 两端键组合。1:N 才是不建表、键放 N 端。

</details>

## 回 6【单选】联系类型的判断

一个班级有多名学生，一名学生只属于一个班级。班级与学生的联系类型是（ ）。

A. 1:1　B. 1:N　C. M:N　D. 无法判断

<details><summary>👉 点开对照答案与解析</summary>

**B（班级 1 : N 学生）。** 拿"一个班级"数 → 多个学生；拿"一名学生"数 → 只属一个班级。只有一边"多"。

</details>
