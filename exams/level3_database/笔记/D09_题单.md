# ② 理论题检测（模块 5e · DML）

## 题 1【判断】DML 是哪三个

`INSERT`、`UPDATE`、`DELETE` 三个语句属于数据操纵语言（DML）。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** DML 管"表里有什么"（数据行）；DDL（CREATE/ALTER/DROP）管"表长什么样"（结构）。口诀：**DDL 装修房子、DML 搬家具**。

</details>

---

## 题 2【单选】插入数据

向表中插入新数据使用（ ）。

A. `INSERT`　B. `UPDATE`　C. `DELETE`　D. `SELECT`

<details><summary>👉 点开对照答案与解析</summary>

**A。** 放数据 = INSERT。B 改、C 删、D 查。DML 三兄弟里"放"是 INSERT。

</details>

---

## 题 3【判断】一次插多行

`INSERT INTO 读者 VALUES ('005','钱七',0), ('006','孙八',1);` 可以一次插入两行。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 多个括号、中间逗号 = 一次插多行。D1 建库时就见过这招。

</details>

---

## 题 4【单选】UPDATE 定位

`UPDATE` 语句里，用来"圈定改哪些行"的子句是（ ）。

A. `SET`　B. `WHERE`　C. `FROM`　D. `ORDER BY`

<details><summary>👉 点开对照答案与解析</summary>

**B。** WHERE 圈范围。A 的 SET 是"改成什么值"（不是圈范围），C、D 不是 UPDATE 的定位子句。

</details>

---

## 题 5【判断】UPDATE 漏 WHERE

`UPDATE 读者 SET 借阅次数 = 0;` 会把读者表**每一行**的借阅次数都改成 0。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 没有 WHERE = 改全表。这就是 DML 的杀伤力所在——WHERE 是"圈范围"的护栏，漏写全表遭殃。**这条别真跑。**

</details>

---

## 题 6【单选】DELETE 漏 WHERE

`DELETE FROM 读者;`（没有 WHERE）执行后会发生（ ）。

A. 删除读者表这一张表
B. 删除读者表里所有行，表结构还在（空表）
C. 只删第一行
D. 报错

<details><summary>👉 点开对照答案与解析</summary>

**B。** DELETE 删**数据行**，表还在（变空表）。A 是 DROP TABLE 的效果（连结构删）。DELETE 漏 WHERE = 删光数据但表保留。

</details>

---

## 题 7【判断】DELETE 与 DROP

`DELETE FROM 表` 删的是数据行（表结构保留），`DROP TABLE 表` 删的是整张表（连结构）。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 口诀：**DELETE 清空抽屉里的东西，DROP 把抽屉整个砸了**。前者 DML、后者 DDL，这是高频判断题。

</details>

---

## 题 8【单选】UPDATE 的关键词

`UPDATE` 语句里，"把某列改成新值"用哪个关键词（ ）。

A. `SET`　B. `VALUES`　C. `CHANGE`　D. `MODIFY`

<details><summary>👉 点开对照答案与解析</summary>

**A。** `UPDATE 表 SET 列=值 WHERE 条件`。B 的 VALUES 是 INSERT 用的；C、D 是 ALTER TABLE 里改列的（DDL），不是改数据。

</details>

---

## 题 9【判断】UPDATE 一次改多列

`UPDATE 读者 SET 借阅次数 = 9, 读者姓名 = '李四改' WHERE ...` 可以一次改两列。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** SET 后面多列用逗号隔开：`SET 列1=值1, 列2=值2`。一次改一行（或多行）的多个列。

</details>

---

## 题 10【单选】DELETE 删的是什么

`DELETE FROM 借阅 WHERE 借阅号 = 8` 删除的是（ ）。

A. 借阅号等于 8 的那一行数据
B. 借阅表这一整张表
C. 借阅号这一列
D. 借阅号等于 8 的所有列

<details><summary>👉 点开对照答案与解析</summary>

**A。** DELETE + WHERE 删的是"满足条件的**行**"，不是列、不是整表。删列要用 ALTER TABLE DROP COLUMN（DDL），删表用 DROP TABLE。

</details>

# ③ 代码实操（换汤不换药：讲义用读者表，这里换图书表/借阅表）

> 每题都是「改 → 看效果 → 恢复现场」三步，**最后一定要恢复**，保持库里数据是你熟悉的 4 读者 / 5 借阅 / 4 图书。

## 实操题 1：INSERT 单行——插一本新书

**要求**：插入一本新书 `('B005','大数据技术','高等教育出版社',3)`，然后 `SELECT * FROM 图书` 看效果，最后 `DELETE` 掉 B005 恢复现场。

**预期输出**（插完 SELECT 图书表，5 行，比原来多一行）：
```
B001  数据库系统概论  高等教育出版社  5
B002  R语言实战      人民邮电出版社  3
B003  Python编程     人民邮电出版社  4
B004  信息检索导论   高等教育出版社  2
B005  大数据技术     高等教育出版社  3   ← 新插的
```

<details><summary>👉 点开折叠答案</summary>

```sql
INSERT INTO 图书 VALUES ('B005','大数据技术','高等教育出版社',3);
SELECT * FROM 图书;
DELETE FROM 图书 WHERE 图书编号 = 'B005';
```

**要点**：`INSERT INTO 图书 VALUES (...)` 按建表列顺序（图书编号/书名/出版社/馆藏量）给全值。最后 `DELETE` 恢复——练完不残留。

</details>

---

## 实操题 2：INSERT 多行——插两个新读者

**要求**：一次插入两个读者 `('005','钱七',0)`、`('006','孙八',1)`，SELECT 看效果，最后 DELETE 恢复。

**预期输出**（插完 SELECT 读者表，6 行）：
```
001  张三  5
002  李四  8
003  王五  3
004  赵六  2
005  钱七  0   ← 新插
006  孙八  1   ← 新插
```

<details><summary>👉 点开折叠答案</summary>

```sql
INSERT INTO 读者 VALUES ('005','钱七',0),('006','孙八',1);
SELECT * FROM 读者;
DELETE FROM 读者 WHERE 读者编号 IN ('005','006');
```

**要点**：多个括号、中间逗号 = 一次插两行。恢复用 `IN ('005','006')` 一次删两个（呼应 D8 的 IN）。

</details>

---

## 实操题 3：UPDATE 单列——改馆藏量

**要求**：把 B002《R语言实战》的馆藏量从 3 改成 6，SELECT 验证，再改回 3 恢复。

**预期输出**（改完 SELECT B002）：
```
B002  R语言实战  人民邮电出版社  6
```

<details><summary>👉 点开折叠答案</summary>

```sql
UPDATE 图书 SET 馆藏量 = 6 WHERE 图书编号 = 'B002';
SELECT * FROM 图书 WHERE 图书编号 = 'B002';
UPDATE 图书 SET 馆藏量 = 3 WHERE 图书编号 = 'B002';
```

**要点**：`SET 馆藏量 = 6` 改值、`WHERE 图书编号='B002'` 圈定只改这一行。最后改回 3——恢复现场。

</details>

---

## 实操题 4：UPDATE 表达式 + 一次多行——人邮的书全 +1

**要求**：把"人民邮电出版社"所有书的馆藏量在原值上加 1（用 `馆藏量 = 馆藏量 + 1`），SELECT 验证，再 -1 恢复。

**预期输出**（改完 SELECT 图书表，注意人邮两行都变了）：
```
B001  数据库系统概论  高等教育出版社  5
B002  R语言实战      人民邮电出版社  4   ← 3 + 1
B003  Python编程     人民邮电出版社  5   ← 4 + 1
B004  信息检索导论   高等教育出版社  2
```

<details><summary>👉 点开折叠答案</summary>

```sql
UPDATE 图书 SET 馆藏量 = 馆藏量 + 1 WHERE 出版社 = '人民邮电出版社';
SELECT * FROM 图书;
UPDATE 图书 SET 馆藏量 = 馆藏量 - 1 WHERE 出版社 = '人民邮电出版社';
```

**要点**：`馆藏量 = 馆藏量 + 1` 是表达式（每行在原值上加 1）；`WHERE 出版社='人民邮电出版社'` 命中 **2 行**，两行一起 +1——**UPDATE 改的是所有满足 WHERE 的行，不是一次一行**。恢复用 -1。

</details>

## 实操题 5：DELETE + 恢复——删一条借阅记录

**要求**：删掉借阅表里"借阅号 = 8"的那一行（赵六借 B001），SELECT 验证，再 INSERT 恢复。

**预期输出**（删完 SELECT 借阅表，4 行，借阅号 8 没了）：
```
借阅号 | 读者编号 | 图书编号 | 应还日期
-------|---------|----------|----------
1      | 001     | B001     | 2026-11-15
2      | 002     | B002     | 2026-11-15
3      | 003     | B003     | 2026-11-20
7      | 004     | B004     | 2026-11-20
```

<details><summary>👉 点开折叠答案</summary>

```sql
DELETE FROM 借阅 WHERE 借阅号 = 8;
SELECT * FROM 借阅;
INSERT INTO 借阅 (读者编号, 图书编号, 应还日期) VALUES ('004','B001','2026-11-25');
```

**要点**：`DELETE ... WHERE 借阅号=8` 只删那一行。恢复时 `INSERT INTO 借阅 (读者编号,图书编号,应还日期)` 指定三列——**借阅号是自增主键，不用填**，它会自动长出来。

⚠️ **恢复后借阅号不是 8 了**（可能是 9 或更大）——**跳号正常**（D3 题 13 见过）：自增号一旦用过就不会回收。借阅日期也会自动填今天（`DEFAULT (CURDATE())` 在干活）。

</details>

# ④ 回炉题（D5 第2轮：聚合 + D8 第1轮：子查询）

> D5 第二轮聚焦"聚合函数 / COUNT 两个面孔 / DISTINCT"（COUNT 是你在 D7 批改时点过的错点，重点回炉）；D8 昨天刚学，今天第一次回炉子查询。

## 回 1【单选】COUNT 的两个面孔

`COUNT(*)` 与 `COUNT(列名)` 的区别是（ ）。

A. `COUNT(*)` 更快
B. `COUNT(列名)` 忽略该列为 NULL 的行
C. `COUNT(*)` 只能用于主键表
D. 没有区别

<details><summary>👉 点开对照答案与解析</summary>

**B。** `COUNT(*)` 数行（NULL 也算）；`COUNT(列)` 只数非 NULL。这条你在 **D7 题 16 亲手踩过**：LEFT JOIN 里用 `COUNT(*)` 会把"没借过书的读者"算成 1，改用 `COUNT(借阅号)` 才是 0。**LEFT JOIN + 数数，永远 COUNT(右表列)**。

</details>

---

## 回 2【单选】聚合忽略 NULL

某列有 4 行：`NULL、3、6、9`，`AVG(该列)` 的结果是（ ）。

A. 4.5　B. 3.6　C. 6　D. 报错

<details><summary>👉 点开对照答案与解析</summary>

**C。** 聚合函数忽略 NULL：(3+6+9)/3 = 6。A 是把 NULL 当 0 算（错）；D 的报错不存在——AVG 遇到 NULL 直接跳过。

</details>

## 回 5【单选】`> ANY` 的含义

`借阅次数 > ANY (3, 2)` 等价于（ ）。

A. `借阅次数 > 3`　B. `借阅次数 > 2`　C. `借阅次数 < 2`　D. `借阅次数 = 3 或 2`

<details><summary>👉 点开对照答案与解析</summary>

**B。** `> ANY` = 比任意一个大就行 = 大于最小的 = `> 2`。ANY 门槛低；对照 `> ALL` = 大于最大的（门槛高）。

</details>

## 回 6【判断】EXISTS 判断什么

`EXISTS (子查询)` 判断的是"子查询有没有返回行"，不关心返回的具体值。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** EXISTS 只看"有没有行"。子查询里写 `SELECT 1` 或 `SELECT *` 都行。相关子查询（内层引用外层）是它的典型用法。

</details>
