# ② 理论题检测（模块 3 · 关系代数）

## 题 1【判断】挑行与挑列

选择运算 σ 是对**行**的筛选，投影运算 π 是对**列**的筛选。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** σ=行（体检刷人）、π=列（只留两栏）。口诀：**σ 横着切（行）、π 竖着切（列）**。

</details>

## 题 2【判断】投影会去重

对课程表做投影 π_课程名(课程) 之后，结果的行数**可能比原表少**。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 投影结果里**重复的行会被合并**——如果原表里有同名课程（不同老师开的同名课），投影后同名行只留一行，行数就变少了。这是判断题爱出的点。

</details>

## 题 3【单选】笛卡儿积的行数

成绩表 A 有 3 行，学生表 B 有 4 行，A × B 的结果有（ ）行。

A. 3　B. 4　C. 7　D. 12

<details><summary>👉 点开对照答案与解析</summary>

**D. 12**。笛卡儿积是"全配对"，行数 = **3 × 4 = 12**（列数 = 3 + 4 = 7）。行列别记混：**行相乘、列相加**。

</details>

## 题 4【单选】找"全能选手"

要查出"**借过图书馆全部图书**"的读者编号，应该用（ ）运算。

A. 选择　B. 投影　C. 连接　D. 除

<details><summary>👉 点开对照答案与解析</summary>

**D. 除**。"借过所有书的读者" = "考过所有科目的学生" = 除运算的含义题。考试只考"含义→选符号"，不考手算。

</details>

## 题 5【单选】差运算的方向

A − B 的结果是（ ）。

A. 既在 A 又在 B 的行
B. 在 A 但不在 B 的行
C. 在 B 但不在 A 的行
D. A、B 的全部行（去重）

<details><summary>👉 点开对照答案与解析</summary>

**B**。差运算**有方向**：A−B = 在 A 不在 B（报名名单减去到场名单 = 放鸽子名单）。C 是 B−A，别搞反。

</details>

## 题 6【单选】并运算的前提

两张表做并运算（∪），必须满足（ ）。

A. 行数相同
B. 主键相同
C. 列数相同、对应列类型相容
D. 表名相同

<details><summary>👉 点开对照答案与解析</summary>

**C**。∪ 是"格式一样的两份表格才能摞起来"——列数相同、对应列类型相容。行数无所谓（A 错），表名无所谓（D 错），主键无关（B 错）。

</details>

## 题 7【单选】自然连接与等值连接

自然连接和等值连接的区别是（ ）。

A. 自然连接不去重
B. 自然连接结果里**没有重复的那一列**（去掉了重复列）
C. 等值连接只能两表连接
D. 没有区别

<details><summary>👉 点开对照答案与解析</summary>

**B**。等值连接按共同列拼起来、**两边的共同列都保留**；自然连接 = 等值连接 + **删掉重复的那一列**。就差这一条。

</details>

## 题 8【单选】关系代数与 SQL 的对照

关系代数里的"选择 + 投影"（σ 加 π），翻译成 SQL 是（ ）。

A. `SELECT 列 FROM 表 WHERE 条件`
B. `INSERT INTO 表 VALUES (...)`
C. `CREATE TABLE 表 (...)`
D. `UPDATE 表 SET 列=值`

<details><summary>👉 点开对照答案与解析</summary>

**A**。σ（挑行）= `WHERE 条件`，π（挑列）= `SELECT 列`。B 是插入、C 是建表、D 是修改（明天 D3 之后的 DML 内容）。

</details>

# ③ 代码实操（换汤不换药：范例用图书表，这里用年级表）

## 题 9【实操】UNION 求并集

**【目的】** 把讲义里"图书A ∪ 图书B"的方法搬到新场景：两张年级读者表合成一张。
**【要求】** 在练习笔记本里建 `读者_大一` 和 `读者_大二` 两张表（建议带 `DROP TABLE IF EXISTS`），**数据已给好、直接抄**，然后用 `UNION` 查出全部读者。

**数据**（照抄即可）：
- 读者_大一：`('001','张三')`、`('002','李四')`、`('003','王五')`
- 读者_大二：`('101','李四')`、`('102','赵六')`、`('103','钱七')`

**验收**：结果 6 行；`'002','李四'` 和 `'101','李四'` 都在（编号不同 → 整行不同 → 不合并）。
**【提示】** 照讲义单元三的范例抄结构、换表名。列就两列：编号 CHAR(3) PRIMARY KEY、姓名 VARCHAR(20)。

<details><summary>👉 点开对照答案与解析</summary>

```sql
%%sql
DROP TABLE IF EXISTS 读者_大一;
CREATE TABLE 读者_大一(编号 CHAR(3) PRIMARY KEY, 姓名 VARCHAR(20));
INSERT INTO 读者_大一 VALUES ('001','张三'),('002','李四'),('003','王五');

DROP TABLE IF EXISTS 读者_大二;
CREATE TABLE 读者_大二(编号 CHAR(3) PRIMARY KEY, 姓名 VARCHAR(20));
INSERT INTO 读者_大二 VALUES ('101','李四'),('102','赵六'),('103','钱七');

SELECT * FROM 读者_大一 UNION SELECT * FROM 读者_大二;
```

真实输出（本机已实测）：

```
001  张三
002  李四      ← 两张表都有，UNION 去重后只留一次
003  王五
101  李四      ← 编号不同所以是不同行，两个"李四"都保留
102  赵六
103  钱七
```

解析：UNION 按**整行**去重——'002','李四' 和 '101','李四' 编号不同，是两行不同的数据，所以都保留；完全相同的行才合并。答案共 6 行（如果两张表里李四的编号也相同，才会合并成 5 行）。

</details>

## 题 10【实操】选择 + 投影（σ + π 的 SQL 实现）

**【目的】** 把"挑行 + 挑列"翻译成 SQL，并顺手回炉 D1 的 WHERE。
**【要求】** 在笔记本里查出**借阅次数大于 3** 的读者的**姓名**（读者表数据已恢复：张三5、李四8、王五3、赵六2）。
**【提示】** 挑行 = `WHERE`，挑列 = `SELECT 后面只写那一列`。写一条 SQL 同时完成两件事。

<details><summary>👉 点开对照答案与解析</summary>

```sql
%%sql
SELECT 读者姓名 FROM 读者 WHERE 借阅次数 > 3;
```

真实输出（本机已实测）：

```
张三
李四
```

解析：执行顺序 **FROM 读者 → WHERE 借阅次数>3（刷掉王五3、赵六2）→ SELECT 读者姓名（只留姓名列）**。这就是 σ 和 π 合体：WHERE 是选择、SELECT 列是投影。

</details>
