## 题 1【判断】存储过程是什么

存储过程是一组**预先编译好**、存在数据库中的 SQL 语句，可以通过名字反复调用。对还是错？

**对。** 预编译 + 存在数据库里 + 用名字调用（讲义单元一）。好处：复用、省网络、快、安全。

</details>

## 题 2【单选】调用存储过程

调用存储过程使用（ ）。

A. `EXEC`　B. `CALL`　C. `RUN`　D. `INVOKE`

<details><summary>👉 点开对照答案与解析</summary>

**B。** MySQL 用 `CALL 过程名(参数)`。`EXEC` 是 SQL Server 的写法——又一个"别把别家语法抄进 MySQL"的坑（跟 TOP/LIMIT 一样）。

</details>

## 题 4【判断】IN 参数

`IN` 参数表示"输入参数"，调用时把值传给存储过程。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** IN = 输入（喂进去）。OUT = 输出（吐出来）。INOUT = 又能进又能出。

</details>

## 题 5【单选】OUT 参数怎么读

调用带 `OUT` 参数的存储过程后，读取输出值应该用（ ）。

A. `SELECT 参数名`
B. `SELECT @用户变量`
C. `SELECT OUT`
D. 过程会直接把值作为结果集返回

<details><summary>👉 点开对照答案与解析</summary>

**B。** OUT 参数调用时用用户变量接：`CALL p('001', @次数); SELECT @次数;`。A 错——参数名只在过程内部可见；D 错——OUT 不是结果集，是"写进变量"。

</details>

## 题 9【单选】参数类型的写法

定义存储过程参数时，类型写法正确的是（ ）。

A. `VARCHAR`　B. `VARCHAR(30)`　C. `STRING`　D. `TEXT(30)`

<details><summary>👉 点开对照答案与解析</summary>

**B。** 参数类型和建表一样，**字符类型必须带长度**：`CHAR(3)`、`VARCHAR(30)`。A 缺长度会报错；C 不是 MySQL 类型；D 的 TEXT 不能写长度。

</details>

# ③ SQL 实操（图书/借阅场景）

> **每题一个 `%%sql` 格**。先写过程，再 `CALL` 验证，做完按题 5 清理。

## 实操题 1：无参存储过程——查所有图书

**要求**：创建存储过程 `p_所有图书`（无参数），过程体查询所有图书的图书编号、书名、出版社、馆藏量，按图书编号排序。然后 `CALL` 验证。

**预期输出**：
```
B001  数据库系统概论  高等教育出版社  5
B002  R语言实战      人民邮电出版社  3
B003  Python编程     人民邮电出版社  4
B004  信息检索导论   高等教育出版社  2
```

<details><summary>👉 点开折叠答案</summary>

```sql
DROP PROCEDURE IF EXISTS p_所有图书;
CREATE PROCEDURE p_所有图书()
BEGIN
  SELECT 图书编号, 书名, 出版社, 馆藏量
  FROM 图书
  ORDER BY 图书编号;
END;
```

调用（另起一格或同一格下一句话）：

```sql
CALL p_所有图书();
```

**要点**：无参就是 `过程名()` 空括号；过程体里一条 SELECT。

</details>

## 实操题 2：IN 参数——查某出版社的书

**要求**：创建 `p_某社图书(IN p_出版社 VARCHAR(30))`，查询该出版社的书名和馆藏量，按馆藏量降序。分别 `CALL` 两次：`'人民邮电出版社'`、`'高等教育出版社'`。

**预期输出**：
```
人民邮电出版社 → Python编程 4 / R语言实战 3
高等教育出版社 → 数据库系统概论 5 / 信息检索导论 2
```

<details><summary>👉 点开折叠答案</summary>

```sql
DROP PROCEDURE IF EXISTS p_某社图书;
CREATE PROCEDURE p_某社图书(IN p_出版社 VARCHAR(30))
BEGIN
  SELECT 书名, 馆藏量
  FROM 图书
  WHERE 出版社 = p_出版社
  ORDER BY 馆藏量 DESC;
END;
```

```sql
CALL p_某社图书('人民邮电出版社');
CALL p_某社图书('高等教育出版社');
```

**要点**：`IN p_出版社 VARCHAR(30)` —— 类型带长度；过程体里当普通变量用。

</details>

## 实操题 3：OUT 参数——统计某本书被借了几次

**要求**：创建 `p_图书借阅次数(IN p_书号 CHAR(4), OUT p_次数 INT)`，统计该书在借阅表里出现几次。用 `CALL` 查 `'B001'` 和 `'B002'`，并把结果 SELECT 出来。

**预期输出**：
```
B001 → 2
B002 → 1
```

<details><summary>👉 点开折叠答案</summary>

```sql
DROP PROCEDURE IF EXISTS p_图书借阅次数;
CREATE PROCEDURE p_图书借阅次数(IN p_书号 CHAR(4), OUT p_次数 INT)
BEGIN
  SELECT COUNT(*) INTO p_次数 FROM 借阅 WHERE 图书编号 = p_书号;
END;
```

```sql
CALL p_图书借阅次数('B001', @次数);
SELECT @次数 AS 借阅次数;
```

```sql
CALL p_图书借阅次数('B002', @次数);
SELECT @次数 AS 借阅次数;
```

**要点**：`SELECT COUNT(*) INTO p_次数` 把结果塞进 OUT 参数；调用时用 `@次数` 接，再 `SELECT @次数` 读出来。

</details>

## 实操题 4：IF + OUT——判断馆藏是否充足

**要求**：创建 `p_馆藏判断(IN p_书号 CHAR(4), OUT p_结果 VARCHAR(20))`：
- 先查出该书的馆藏量（用 `DECLARE` 局部变量接）
- 馆藏量 **≥ 4** → 输出 `'充足'`；否则 → `'不足'`

分别测 `'B001'`（馆藏 5）和 `'B004'`（馆藏 2）。

**预期输出**：
```
B001 → 充足
B004 → 不足
```

<details><summary>👉 点开折叠答案</summary>

```sql
DROP PROCEDURE IF EXISTS p_馆藏判断;
CREATE PROCEDURE p_馆藏判断(IN p_书号 CHAR(4), OUT p_结果 VARCHAR(20))
BEGIN
  DECLARE v_馆藏 INT;
  SELECT 馆藏量 INTO v_馆藏 FROM 图书 WHERE 图书编号 = p_书号;
  IF v_馆藏 >= 4 THEN
    SET p_结果 = '充足';
  ELSE
    SET p_结果 = '不足';
  END IF;
END;
```

```sql
CALL p_馆藏判断('B001', @结果); SELECT @结果 AS 判断;
CALL p_馆藏判断('B004', @结果); SELECT @结果 AS 判断;
```

**要点**：`DECLARE` 放在 BEGIN 后第一行；`SELECT ... INTO` 取值；IF...THEN...ELSE...**END IF**。

</details>

## 实操题 5：IN 参数 + INSERT——新增图书，然后清理

**要求**：
① 创建 `p_新增图书(IN p_编号 CHAR(4), IN p_书名 VARCHAR(50), IN p_馆藏 INT)`，向图书表插入一行（只给编号、书名、馆藏量，出版社走默认值）。
② `CALL p_新增图书('B009','测试书',2);` 然后查 `B009` 验证。
③ 删除 B009（恢复数据）。
④ **`DROP PROCEDURE` 把今天创建的 5 个过程全部删掉**，用 `SHOW PROCEDURE STATUS WHERE Db='exam_practice';` 确认空了。

**预期**：B009 的出版社自动是"未知出版社"；最后过程列表为空。

<details><summary>👉 点开折叠答案</summary>

```sql
DROP PROCEDURE IF EXISTS p_新增图书;
CREATE PROCEDURE p_新增图书(IN p_编号 CHAR(4), IN p_书名 VARCHAR(50), IN p_馆藏 INT)
BEGIN
  INSERT INTO 图书(图书编号, 书名, 馆藏量) VALUES (p_编号, p_书名, p_馆藏);
END;
```

```sql
CALL p_新增图书('B009','测试书',2);
SELECT * FROM 图书 WHERE 图书编号 = 'B009';
DELETE FROM 图书 WHERE 图书编号 = 'B009';
```

真实输出（本机已实测）：
```
B009 | 测试书 | 未知出版社 | 2
```
（出版社没给，DEFAULT '未知出版社' 自动补上。）

```sql
DROP PROCEDURE IF EXISTS p_所有图书;
DROP PROCEDURE IF EXISTS p_某社图书;
DROP PROCEDURE IF EXISTS p_图书借阅次数;
DROP PROCEDURE IF EXISTS p_馆藏判断;
DROP PROCEDURE IF EXISTS p_新增图书;
SHOW PROCEDURE STATUS WHERE Db = 'exam_practice';
```

**要点**：存储过程可以执行 DML（INSERT/UPDATE/DELETE）。清理时用 `DROP PROCEDURE IF EXISTS` 逐个删。

</details>

## 回 4【单选】2NF 消除什么

## 回 5【判断】没有非主属性的表

一张表如果没有非主属性（所有属性都是主属性），它一定满足 3NF。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**对。** 3NF 管的是"非主属性的部分/传递依赖"，没有非主属性就无从违反。但它**不一定**满足 BCNF。

</details>

---

## 回 6【判断】3NF 与 BCNF

一个关系模式如果满足 3NF，那么它一定满足 BCNF。对还是错？

<details><summary>👉 点开对照答案与解析</summary>

**错。** 方向反了：**BCNF 比 3NF 严格**。满足 BCNF 一定满足 3NF；满足 3NF 不一定满足 BCNF（经典反例：学生-课程-教师，全是主属性，是 3NF 但不是 BCNF）。

</details>
