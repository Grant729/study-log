## 题 41（10 分）ER 设计 + 转关系模式

**需求**：某学校图书馆——

- **读者**：读者编号、姓名、电话
- **图书**：图书编号、书名
- **出版社**：出版社编号、出版社名
- 一个出版社可以出版多本图书，一本图书只属于一个出版社
- 一个读者可以借多本图书，一本图书可以被多个读者借阅
- 借阅要记录**借阅日期、应还日期**

**要求**：
1. （4 分）指出两个联系各自的类型（1:1 / 1:N / M:N），并说明理由
2. （3 分）写出 ER 图的三要素（实体及属性、联系及类型）
3. （3 分）转换成关系模式，标出每张表的主键和外键

<details><summary>👉 答案与解析</summary>

**1. 联系类型（4 分）**

- **出版**：图书 N — 1 出版社。
  - 一个出版社 → 多本图书；一本图书 → 只属于一个出版社 → **1:N**
- **借阅**：读者 M — N 图书。
  - 一个读者 → 多本书；一本书 → 多个读者 → **M:N**

**2. ER 三要素（3 分）**

- 实体：读者(<u>读者编号</u>, 姓名, 电话)、图书(<u>图书编号</u>, 书名)、出版社(<u>出版社编号</u>, 出版社名)
- 联系：出版（图书 N — 1 出版社）、借阅（读者 M — N 图书，属性：借阅日期、应还日期）
- （主键属性在椭圆里加下划线；实体=矩形、属性=椭圆、联系=菱形）

**3. 关系模式（3 分）**

```
读者( 读者编号, 姓名, 电话 )
出版社( 出版社编号, 出版社名 )
图书( 图书编号, 书名, 出版社编号 )              ← 1:N，1 端键放 N 端；外键：出版社编号
借阅( 读者编号, 图书编号, 借阅日期, 应还日期 )   ← M:N，单独建表
      主键 = (读者编号, 图书编号)
      外键：读者编号 → 读者；图书编号 → 图书
```

**评分要点**：1:N 不建表（2 分）、M:N 单独建表且主键为组合键（2 分）、主外键标对（2 分）。

</details>

## 题 42（10 分）SQL 综合

> ⚠️ **执行说明（重要，2026-10-20 修订）**
> 你的库里**已经有 `借阅` 表和 5 行数据**，所以建表题不能直接 `DROP TABLE 借阅` 再重建（重建后表是空的，第 2、3 问就没数据可查了）。
> **正确做法**：
> - 第 1 问按**纸面**作答；想实际验证语法，把表名换成 **`借阅_模拟`**，验证完 `DROP TABLE 借阅_模拟;`
> - 第 2、3 问直接用**现有的** `读者` / `借阅` 表（有数据）

**已知表**：
- `读者(读者编号, 读者姓名, 借阅次数)`
- `借阅(借阅号, 读者编号, 图书编号, 借阅日期, 应还日期, 归还日期)`
- `图书(图书编号, 书名, 出版社, 馆藏量)`

**要求**：

1. （3 分）写出创建 `借阅` 表的 SQL：借阅号自增主键；读者编号、图书编号为**非空外键**；借阅日期默认当天；应还日期非空；另有归还日期。
2. （3 分）查询"借阅次数最多的读者的姓名"（用子查询，不要写死数值）。
3. （4 分）查询每个读者的姓名和借阅本数，**没借过书的也要显示（本数 0）**，按借阅本数降序。

<details><summary>👉 答案与解析</summary>

**1. 建表（3 分）**

```sql
CREATE TABLE 借阅 (
  借阅号   INT PRIMARY KEY AUTO_INCREMENT,
  读者编号 CHAR(3) NOT NULL,
  图书编号 CHAR(4) NOT NULL,
  借阅日期 DATE DEFAULT (CURDATE()),
  应还日期 DATE NOT NULL,
  归还日期 DATE,
  FOREIGN KEY (读者编号) REFERENCES 读者(读者编号),
  FOREIGN KEY (图书编号) REFERENCES 图书(图书编号)
);
```

**实际验证版**（把表名换掉，其余完全一样）：

```sql
DROP TABLE IF EXISTS 借阅_模拟;
CREATE TABLE 借阅_模拟 (
  借阅号   INT PRIMARY KEY AUTO_INCREMENT,
  读者编号 CHAR(3) NOT NULL,
  图书编号 CHAR(4) NOT NULL,
  借阅日期 DATE DEFAULT (CURDATE()),
  应还日期 DATE NOT NULL,
  归还日期 DATE,
  FOREIGN KEY (读者编号) REFERENCES 读者(读者编号),
  FOREIGN KEY (图书编号) REFERENCES 图书(图书编号)
);
DESCRIBE 借阅_模拟;
DROP TABLE 借阅_模拟;
```

**2. 借阅次数最多的读者（3 分）**

```sql
SELECT 读者姓名
FROM 读者
WHERE 借阅次数 = (SELECT MAX(借阅次数) FROM 读者);
```

结果：**李四**（8 次）。

**3. 每个读者姓名 + 借阅本数（4 分）**

```sql
SELECT 读者.读者姓名, COUNT(借阅.图书编号) AS 借阅本数
FROM 读者
LEFT JOIN 借阅 ON 读者.读者编号 = 借阅.读者编号
GROUP BY 读者.读者编号, 读者.读者姓名
ORDER BY 借阅本数 DESC;
```

结果：赵六 2、张三 1、李四 1、王五 1。

⚠️ **三个常见写法错误（对照检查）**：

| 错误写法 | 正确写法 | 为什么 |
|---|---|---|
| `REFERENCES 读者.读者编号` | `REFERENCES 读者(读者编号)` | 外键固定句式是 `REFERENCES 父表(列)`，**括号**不是点号 |
| `应换日期 VARCHAR(20)` | `应还日期 DATE` | 错别字；日期要用 `DATE` 类型 |
| 借阅号用自增代理键当主键（ER 转换题） | ER 转换的标准答案用 `(读者编号, 图书编号)` 组合键 | 考试按标准答案；代理键是工程做法 |

**评分要点**：第 3 题必须用 **LEFT JOIN**（保住没借过书的读者）和 **`COUNT(借阅.图书编号)`**（不能用 `COUNT(*)`，否则没借过书的会算成 1——你错题本 #4）。

## 题 43（10 分）存储过程 + 触发器

1. （5 分）创建存储过程 `p_借阅本数`：输入读者编号（IN），输出该读者的借阅本数（OUT）。写出创建语句和调用语句。
2. （5 分）创建触发器 `trg_删借阅减次数`：删除一条借阅记录时，自动把对应读者的借阅次数减 1。

<details><summary>👉 答案与解析</summary>

**1. 存储过程（5 分）**

```sql
CREATE PROCEDURE p_借阅本数(IN p_编号 CHAR(3), OUT p_本数 INT)
BEGIN
  SELECT COUNT(*) INTO p_本数 FROM 借阅 WHERE 读者编号 = p_编号;
END;
```

调用：

```sql
CALL p_借阅本数('004', @本数);
SELECT @本数;
-- → 2
```

**评分要点**：参数方向写对（IN/OUT 各 1 分）、`SELECT ... INTO`（2 分）、调用用 `@变量`（1 分）。

**2. 触发器（5 分）**

```sql
CREATE TRIGGER trg_删借阅减次数
AFTER DELETE ON 借阅
FOR EACH ROW
BEGIN
  UPDATE 读者 SET 借阅次数 = 借阅次数 - 1
  WHERE 读者编号 = OLD.读者编号;
END;
```

**评分要点**：`AFTER DELETE ON 借阅`（2 分）、`FOR EACH ROW`（1 分）、用 **`OLD.读者编号`**（2 分——用 NEW 是错的，DELETE 没有 NEW）。

</details>
