## 单元一：什么是存储过程——把一串 SQL "打包成一个名字"

### 先看一个痛点

你已经会写这样的查询：

```sql
SELECT 借阅号, 图书编号, 应还日期
FROM 借阅
INNER JOIN 图书 ON 借阅.图书编号 = 图书.图书编号
WHERE 借阅.读者编号 = '001'
ORDER BY 借阅.应还日期;
```

如果每天都要查不同读者的借阅记录，你得**每次改编号、重新发一遍**。

**存储过程**就是解决这个的：

> **把一串 SQL 语句预先存在数据库里，起个名字。以后只要 `CALL 名字(参数)` 就能执行。**

**比喻**：像**点套餐**。
- 零散点菜 = 每次一条条发 SQL（传很多指令给后厨）
- 套餐 = 后厨提前配好一套流程，你只要说"来一份 A 套餐"（`CALL 套餐A()`）

### 存储过程的四个好处（客观题考点）

| 好处 | 说明 |
|---|---|
| **复用** | 写一次，到处 CALL |
| **减少网络传输** | 不用每次都把一大串 SQL 发给服务器，只发一个 `CALL` |
| **执行更快** | 存储过程是**预编译**的，数据库提前解析好 |
| **更安全** | 用户只能 CALL，看不到也改不了里面的表和逻辑 |

## 单元二：基本骨架——创建 / 调用 / 删除 / 查看

### 创建

```sql
CREATE PROCEDURE 过程名()
BEGIN
  -- 一串 SQL 语句
END;
```

**逐词**：
- `CREATE PROCEDURE 名字()` —— 创建过程，括号里放参数（没有就是空括号）
- `BEGIN ... END` —— 过程体，里面可以写**多条** SQL，每条以 `;` 结尾
- 过程体最后 `END;` 收尾

### 调用

```sql
CALL 过程名();
```

### 删除

```sql
DROP PROCEDURE IF EXISTS 过程名;
```

### 查看

```sql
SHOW PROCEDURE STATUS WHERE Db = 'exam_practice';
```

⚠️ **重要提醒（Jupyter 特有）**：教材上常见 `DELIMITER //` 这种写法——那是 **mysql 命令行客户端**为了区分"过程体内的分号"和"语句结束"才需要的。**在你现在的 Jupyter 笔记本里不用写 `DELIMITER`**，直接 `CREATE PROCEDURE ... END;` 就能建（我已在你的 MySQL 8.0.23 上实测）。

## 单元三：无参存储过程——最简单的形态

**需求**：查所有读者。

```sql
CREATE PROCEDURE p_所有读者()
BEGIN
  SELECT 读者编号, 读者姓名, 借阅次数 FROM 读者 ORDER BY 读者编号;
END;
```

调用：

```sql
CALL p_所有读者();
```

真实输出（本机已实测）：

```
读者编号 | 读者姓名 | 借阅次数
001     | 张三    | 5
002     | 李四    | 8
003     | 王五    | 3
004     | 赵六    | 2
```

**读法**：过程体里就一条 `SELECT`，CALL 一下就把结果集返回给你。**无参 = 不需要输入，结果固定**。

## 单元四：IN 参数——给过程"喂"一个值

**需求**：查**某个读者**的借阅记录。编号是变化的，所以要传进去。

### 语法：`IN 参数名 类型`

```sql
CREATE PROCEDURE p_读者借阅(IN p_编号 CHAR(3))
BEGIN
  SELECT 借阅.借阅号, 图书.书名, 借阅.应还日期
  FROM 借阅
  INNER JOIN 图书 ON 借阅.图书编号 = 图书.图书编号
  WHERE 借阅.读者编号 = p_编号
  ORDER BY 借阅.应还日期;
END;
```

调用：

```sql
CALL p_读者借阅('001');
```

真实输出：

```
借阅号 | 书名         | 应还日期
1      | 数据库系统概论 | 2026-11-15
```

换成 `CALL p_读者借阅('004');`：

```
借阅号 | 书名         | 应还日期
7      | 信息检索导论   | 2026-11-20
9      | 数据库系统概论 | 2026-11-25
```

**要点**：
- `IN` = **输入**，调用时把值传进来
- 过程体里像用普通变量一样用 `p_编号`（参数名建议加前缀 `p_`，一眼看出是参数）
- 参数类型要**带长度**：`CHAR(3)`、`VARCHAR(30)`——不能只写 `VARCHAR`

## 单元五：OUT 参数——让过程"吐"一个值出来

IN 是"喂进去"，OUT 是"**拿出来**"。区别在于：**OUT 参数不给你传值，而是过程算完把结果写进它，你调用完再去读**。

### 语法：`OUT 参数名 类型`

**需求**：统计某个读者借了几本书，把**数量**输出。

```sql
CREATE PROCEDURE p_借阅次数(IN p_编号 CHAR(3), OUT p_次数 INT)
BEGIN
  SELECT COUNT(*) INTO p_次数 FROM 借阅 WHERE 读者编号 = p_编号;
END;
```

**关键句**：`SELECT COUNT(*) INTO p_次数` —— 把查出来的数**塞进 OUT 参数**（不是返回结果集）。

### 怎么调用 OUT 参数

OUT 参数调用时要用**用户变量 `@变量名`** 接：

```sql
CALL p_借阅次数('004', @次数);
SELECT @次数 AS 借阅次数;
```

真实输出：

```
借阅次数
2
```

（004 赵六借了 2 本。）

**逐词理解**：
- `@次数` 是**用户变量**（会话级，`@` 开头），先当"空杯子"传进去
- 过程跑完，把 2 倒进这个杯子
- 第二个 `SELECT @次数` 把杯子里的值显示出来

⚠️ **不是 `SELECT p_次数`**——参数名只存在于过程内部，外面看不见。外面要用 `@次数`。

### IN 和 OUT 放一起

```sql
CREATE PROCEDURE p_借阅次数(IN p_编号 CHAR(3), OUT p_次数 INT)
```

- 第一个参数：`IN`，调用的输入
- 第二个参数：`OUT`，调用后读的输出

**比喻**：IN = 你递给后厨的食材；OUT = 后厨递给你的成品。

## 单元六：INOUT 参数（简提）

`INOUT` = **既是输入又是输出**：调用时给一个值，过程里改它，调用后读新值。

```sql
CREATE PROCEDURE p_加倍(INOUT p_数 INT)
BEGIN
  SET p_数 = p_数 * 2;
END;
```

调用：

```sql
SET @x = 10;
CALL p_加倍(@x);
SELECT @x;   -- 20
```

**考试重点**：大纲明确写的是 **IN / OUT**，`INOUT` 知道有这回事即可，考到判断/选择题能认出来。

## 单元七：变量与 IF——让过程"会思考"

### 两种变量，别混

| 类型 | 写法 | 在哪声明 | 作用范围 |
|---|---|---|---|
| **局部变量** | `DECLARE v_馆藏 INT;` | **过程体内**（BEGIN 后）| 只在过程里 |
| **用户变量** | `@次数` | 不用声明，直接用 | 整个会话 |

⚠️ **`DECLARE` 必须放在 `BEGIN` 之后、其他语句之前**（先声明再使用）。

### 赋值

```sql
SELECT 馆藏量 INTO v_馆藏 FROM 图书 WHERE 图书编号 = 'B001';   -- 查询结果塞进变量
SET v_馆藏 = 10;                                              -- 直接赋值
```

### IF 判断

**需求**：馆藏量 ≥ 4 输出"充足"，否则"不足"。

```sql
CREATE PROCEDURE p_馆藏判断(IN p_书号 CHAR(4), OUT p_结果 VARCHAR(20))
BEGIN
  DECLARE v_馆藏 INT;
  SELECT 馆藏量 INTO v_馆藏 FROM 图书 WHERE 图书编号 = p_书号;
  IF v_馆藏 >= 4 THEN
    SET p_结果 = '充足';
  ELSE
    SET p_结果 = '不足';
  END IF;
END;
```

调用：

```sql
CALL p_馆藏判断('B001', @结果); SELECT @结果;   -- 充足（馆藏 5）
CALL p_馆藏判断('B004', @结果); SELECT @结果;   -- 不足（馆藏 2）
```

**语法要点**：
- `IF 条件 THEN ... ELSE ... END IF;` —— **`END IF` 不能漏**
- 条件里用普通的比较运算符（`>=`、`<`、`=`）

## 单元八：三种参数对比 + 今日自查

| 参数类型 | 方向 | 调用时 | 过程里怎么用 | 调用后读 |
|---|---|---|---|---|
| **无参数** | — | `CALL p()` | — | 结果集 |
| **IN** | 传入 | `CALL p('001')` | 当变量用（`p_编号`）| — |
| **OUT** | 传出 | `CALL p(@变量)` | 给它赋值（`SELECT ... INTO` / `SET`）| `SELECT @变量` |
| **INOUT** | 传入+传出 | `CALL p(@变量)` | 先读再改 | `SELECT @变量` |
