# projects/ — 模拟项目存档（一个项目一个文件夹）

> 规则：每个模拟项目独立建文件夹，命名 `NNN_主题`（如 `001_borrow_report`）。
>
> 项目文件夹内部结构约定：
> - `01_pipeline.ipynb` — Python 内核笔记本（取数/入库/清洗/加工；SQL 用 `%%sql` 魔法单元格，MySQL 直连）
> - `02_analysis.ipynb` — R 内核笔记本（统计分析 / ggplot2 可视化 / 结论）
> - `data/` — 项目输入数据与中间产物
> - `outputs/` — 图、报告、截图等产出
>
> 完整大项目（项目 1、文献计量、项目 2）可各自独立建 GitHub repo，在这里留链接。
